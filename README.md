# Startup Profit Analysis

An end-to-end Data Analytics project focused on analyzing startup financial performance, identifying profitability drivers, and generating business insights using Excel, SQL, Python, and Power BI.

## Project Overview

This project analyzes startup investment and profit data to understand how Research & Development, Administration, and Marketing expenditures influence business profitability.

## Objectives

- Analyze startup profitability across different states.
- Evaluate the relationship between business investments and profit.
- Identify the most influential factors affecting profitability.
- Build an interactive dashboard for business performance monitoring.
- Apply regression analysis to understand and predict startup profit.

## Tools & Technologies

- **Excel:** Data analysis and reporting
- **SQL:** Data querying and analysis
- **Python:** Data cleaning, exploratory data analysis, and regression
- **Power BI:** Interactive dashboard and visualization

## Key Findings

- R&D expenditure showed a strong positive correlation with profit (0.9729).
- The regression model achieved an R² score of approximately 95.07%.
- Profitability was compared across California, Florida, and New York.
- The analysis explored the impact of R&D, Administration, and Marketing expenditure on startup profit.

## Regression Model

The multiple linear regression model achieved:

- **R² Score:** 0.9507
- **MAE:** 6,471.45
- **RMSE:** 8,855.34
