# 📊 Startup Profit Analysis

### An End-to-End Data Analytics Project Using Excel, SQL, Python & Power BI

An end-to-end data analytics project focused on understanding startup profitability, evaluating investment patterns, and identifying the key factors influencing business performance.

---

## 📌 Project Overview

The objective of this project is to analyze startup financial data and understand how Research & Development (R&D), Administration, and Marketing expenditures influence startup profitability.

The project covers data analysis, SQL querying, exploratory data analysis, regression modelling, and interactive dashboard development.

## 🎯 Project Objectives

- Analyze startup profitability across different states.
- Evaluate the relationship between business investments and profit.
- Identify the impact of R&D, Administration, and Marketing expenditure.
- Compare profitability across California, Florida, and New York.
- Build an interactive dashboard to communicate business insights.
- Apply regression analysis to understand and predict startup profit.

## 📈 Key Findings

- R&D expenditure showed a strong positive correlation with profit (0.9729).
- Florida recorded the highest average profit among the three states at approximately $118,774.
- The regression model achieved an R² score of approximately 95.07%.
- The analysis explored how R&D, Administration, and Marketing expenditures relate to startup profitability.

## 🤖 Regression Model Performance

Multiple Linear Regression was used to analyze the relationship between investment expenditure and startup profit.

| Evaluation Metric | Result |
|---|---:|
| R² Score | 0.9507 |
| MAE | 6,471.45 |
| RMSE | 8,855.34 |

The model explains approximately 95.07% of the variation in profit within this dataset.

## 💡 Business Insights

- R&D investment has a strong positive relationship with startup profit.
- Investment allocation should be evaluated alongside profitability outcomes.
- State-wise analysis helps compare regional business performance.
- Regression analysis provides an additional way to understand the relationship between financial investments and profit.
